# 向上 · 成长奖励面板

教师管理与学生成长展示的静态网页项目。在线演示内的姓名、学校、成绩、参考线、日期与金额全部为独立生成的虚拟示例，不包含真实学生资料，也不包含原始工作簿。

- [演示首页](https://yusheng266186-beep.github.io/xiangshang-growth-dashboard/)
- [教师管理看板](https://yusheng266186-beep.github.io/xiangshang-growth-dashboard/teacher.html)
- [学生成长面板](https://yusheng266186-beep.github.io/xiangshang-growth-dashboard/student.html)

## 使用

直接打开 `index.html`，或通过上面的在线地址访问。教师版支持本地 Excel 导入、考试与班级选择、奖励金额与场次设置、核对及发放记录，以及生成独立学生网页。学生版提供奖励明细、成长轨迹、学科分析与目标推演。

本地 Excel 由浏览器读取和解析，无服务器上传接口。导出文件下载到本地；导入后不会自动改变 GitHub 仓库或公开演示。涉及真实学生的教师备份、生成网页和发放记录应保留在本地，不要加入公开仓库。

首次导入表格时，教师版按所选考试和班级建立正式固定名单，不再拿虚拟同学进行匹配。正式名单建立后，后续导入仍会检查名单外学生；未收录成绩需要确认缺考或未参加。切换班级保留正式档案，演示名单和演示账目不进入正式档案。

名单默认按最近一次考试总分从高到低排列，缺考学生排在最后。内部身份编号仅用于连接历史记录，不显示在姓名旁。

生成的学生版是独立 HTML，包含字体、图形、成绩与兑换余额，不包含首页或教师版跳转，也不显示数据处理提示。可复制到教室电脑直接打开。

成绩、金额设置与兑换记录自动保存在本机浏览器的 IndexedDB。同一浏览器刷新或重新打开教师版时会恢复最近账目；状态栏显示保存结果。其他教师标签页写入了新账目时，旧页面不会覆盖这些记录，需要重新打开以恢复最新账目。

登记兑换后，可另外保存最新教师版并更新学生版。下次继续导入时，已兑换金额、确认快照和历史奖金都会保留，新考试奖金另行计算。新表可以只含本次考试，无需重复携带原起点与首场成绩。

本机自动保存不提供跨设备或跨浏览器同步。清除网站数据、使用无痕窗口或更换电脑前，请保存教师文件或完整教师备份；在新设备打开该文件，或恢复备份后继续。浏览器不支持本机存储或保存失败时，状态栏会提示保存教师文件。真实资料不会上传到公开 GitHub 或其他服务器。

## 演示数据与规则

演示有24位“演示同学”，三场虚拟考试（起点、首场、第二场），年级参考人数为208、228、227，第二场包含一位虚拟缺考同学。六科成绩、题目得分与参考线均为虚构；学期示例预算3600元，六场各600元，每人每场参与奖6元。

保留第14版奖励规则：首场成果按60%校准；后续年级进步按70%本场与30%近期成果计算；差考不降低首场参照；缺考不按零分计奖。教师设置仅改变金额与场次，不改变这些规则。

## 目录与发布

- `index.html`：演示入口。
- `teacher.html`：教师版，自带虚拟数据与生成学生版所需的虚拟模板。
- `student.html`：学生版，自带虚拟数据。
- `scripts/verify-public-data.mjs`：校验两个页面及内嵌模板只含约定的虚拟数据。
- `tests/import-roster.test.mjs`：首次导入、固定名单保护和档案隔离的回归测试，全部使用虚拟数据。

发布前运行 `node scripts/verify-public-data.mjs` 和 `node --test tests/import-roster.test.mjs`。GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 保持文件直接作为静态页面部署。

网页自带字体和浏览器端解析依赖，可直接下载离线使用；这些资源的许可证说明保留在网页源码中。
